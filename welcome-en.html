What does T-Browser do?

It is a browser that blocks images, video, and other heavy resources before they load, so you use less mobile data. Text still reads normally, so news and research work as usual.

Out of the box it blocks images, media (video & audio), fonts, and pop-ups, while stylesheets and JavaScript are allowed. If a page breaks and you cannot read it, you can loosen any of these individually in Settings.

Try the blocking

Everything below actually tries to load something. Change a toggle in ••• → Settings, then reload this page to see the result change.

  • Images
  • Media (video & audio)
  • Fonts
  • Stylesheets
  • JavaScript

1. Images

Blocked: you get a dashed placeholder box.
Allowed: a blue image reading “Image loaded” appears.

2. Media (video & audio)

Blocked: it will not play — the frame stays black or fails to load.
Allowed: pressing play shows “Video is playing”.

3. Fonts

With a web font MOJI BROWSER 12345
For comparison (system font) MOJI BROWSER 12345

Blocked: both lines look the same — the system font is used for each.
Allowed: only the top line turns into a pixel font.

4. Stylesheets

✅ The external stylesheet was applied 🚫 The external stylesheet is blocked A green border means it loaded.

Blocking stylesheets also strips the styling from this page. Text stays readable, but many sites will look broken, so leaving this on all the time is usually not worth it.

5. JavaScript

🚫 The external script is blocked Either JavaScript blocking is on, or the script could not load.

Blocking JavaScript saves a lot of data, but many sites stop working. It is usually best to leave it allowed and turn it off only when you need to. When you want to allow it for just one page, use ••• → Allow JavaScript on This Page and ReloadPro.

6. Pop-ups

Try a link that opens a new window Tapping it asks for a new window.

Blocked: “Pop-up blocked” appears at the bottom and nothing opens.
Allowed: the page opens in a new tab.

Changing settings

  1. Tap ••• at the bottom of the screen
  2. Choose Settings
  3. Flip any toggle under “Resources to Block” (changes apply immediately)
  4. Come back here and tap ↻ to reload and see the difference

What Pro adds

  • Press and hold to show an imagePro
    Press and hold a blocked image to load just that one image. Normal blocking resumes as soon as you navigate away, so you use very little data. If you would rather keep the standard iOS link preview, you can switch this off in Settings.
  • Per-site settingsPro
    Save exceptions per domain, such as “allow images on this site only”. Find it under ••• → Settings for This Site.
  • Allow JavaScript on one pagePro
    Reload a broken page with JavaScript allowed, just that once. It reverts automatically on the next page you open.

Questions

The page is blank or looks broken

Usually that is the stylesheet or JavaScript blocking. Try ••• → Allow JavaScript on This Page and ReloadPro, or turn the matching toggle off in Settings.

I cannot sign in to a site

Turn JavaScript blocking off and try again.

How much data will I actually save?

It depends on the site, but on image-heavy pages most of the download is images. Blocking images only is the sweet spot: big savings, and very little breaks.
