モジブラ（T-Browser）に関するよくある質問とお問い合わせ

日本語のあと英語が続きます。English follows below.

モジブラとは

モジブラは、画像・動画などの読み込みをブロックして通信量を節約する、文字中心のWebブラウザです。ニュースなどを「文字だけ」で軽く読みたいときに役立ちます。

よくある質問

画像や動画が表示されません

仕様です。初期状態では画像・メディア・フォントの読み込みをブロックして通信量を節約します。表示したい場合は、設定画面から各リソースのブロックを OFF にしてください。

特定の画像だけを見たい

有料機能（Pro）では、ブロックされた画像を長押しすると、その画像だけ一時的に表示できます。ページを移動すると通常のブロック設定に戻ります。設定で「長押しで画像を表示（プレビュー抑制）」の ON/OFF を切り替えられます。

サイトが正しく表示されない・真っ白になる

一部のサイトはスクリプト（JavaScript）やスタイルシートに依存しており、これらをブロックすると正しく表示されないことがあります。設定でスクリプト／スタイルシートのブロックを OFF にするか、Pro の「このページで JavaScript を許可して再読込」をお試しください。

検索エンジンを変えたい

設定画面から、Google と Yahoo! JAPAN を切り替えられます。

購入した Pro が反映されない／機種変更した

ペイウォール画面の「購入を復元」をタップしてください。同じ Apple ID での購入内容が復元されます。

無料でどこまで使えますか

インストールから 3 日間はすべての機能をお試しいただけます。その後も無料で、画像のブロックはずっと有効のままお使いいただけます。動画・スタイルシート・スクリプト・フォントの切り替え、長押しでの一時表示、サイトごとの設定、一時 JavaScript 許可は買い切りの Pro でご利用いただけます。

ブックマークが消えないか心配です

ブックマークは iCloud にも保存されます。アプリを削除して入れ直したり、機種変更したりしても、同じ Apple ID で iCloud にサインインしていれば自動的に復元されます。手動で HTML ファイルに書き出して保存しておくこともできます（ブックマーク画面の「•••」→「HTMLファイルに書き出す」）。

Safari や Chrome のブックマークを移したい

iPhone 版の Safari・Chrome にはブックマークの書き出し機能がないため、パソコン側で書き出したファイルを使います。

  1. パソコンの Safari なら「ファイル」→「書き出す」→「ブックマーク」、Chrome / Edge / Firefox ならブックマークマネージャの「ブックマークを HTML ファイルにエクスポート」を選ぶ
  2. できた HTML ファイルを iCloud Drive などに保存して、iPhone の「ファイル」アプリから見えるようにする
  3. モジブラのホーム画面 →「編集」→ 右上の「•••」→「HTMLファイルから読み込む」で、そのファイルを選ぶ

フォルダも一緒に取り込まれます（入れ子のフォルダは 1 階層にまとめられます）。すでに登録済みの URL は重複しません。

Support

Frequently asked questions and contact for T-Browser

About T-Browser

T-Browser is a text-first web browser that saves mobile data by blocking images, video, and other heavy resources. It is handy for reading news and articles as text.

Frequently Asked Questions

Images and videos don't appear

This is by design. By default, images, media, and fonts are blocked to save data. To show them, turn off blocking for each resource in Settings.

I want to see just one image

With the paid feature (Pro), long-press a blocked image to load just that image. Normal blocking resumes after you navigate to another page. You can toggle "reveal on long-press (suppress preview)" in Settings.

A site looks broken or blank

Some sites depend on JavaScript or stylesheets and may not render correctly when these are blocked. Turn off script/stylesheet blocking in Settings, or try Pro's "Allow JavaScript on this page and reload."

Changing the search engine

You can switch between Google and Yahoo! JAPAN in Settings.

My Pro purchase isn't recognized / I changed devices

Tap "Restore Purchases" on the paywall screen to restore purchases made with the same Apple ID.

What is included for free?

All features are unlocked for the first 3 days after installation. After that the app stays free with image blocking always on. Toggling media, stylesheets, scripts, and fonts, plus long-press reveal, per-site settings, and temporary JavaScript are part of the one-time Pro purchase.

Will I lose my bookmarks?

Bookmarks are mirrored to iCloud, so they are restored automatically when you reinstall the app or switch devices, as long as you are signed in to iCloud with the same Apple ID. You can also export them to an HTML file for safekeeping.

Importing bookmarks from Safari or Chrome

Safari and Chrome on iPhone cannot export bookmarks, so export them on a computer first.

  1. Desktop Safari: File → Export → Bookmarks. Chrome / Edge / Firefox: Bookmark manager → Export bookmarks to HTML file.
  2. Save the HTML file to iCloud Drive so it appears in the Files app on your iPhone.
  3. In T-Browser, go to Home → Edit → "•••" → Import from HTML file, and pick the file.

Folders are imported too (nested folders are flattened to one level), and duplicate URLs are skipped.
